# 0.11.12 本地验收记录

日期：2026-11-01。范围：确认后的 Demo 融合、单证顶部工具和紧凑抬头、产品字段模板、客户概览、历史记录性能。

## 实际改动

- 新增 `assets/approved-workspace.css`，统一新建入口、顶部工具、历史列表和客户概览样式。填写区与预览上下排列。
- `app.js` 将现有语言、配色、商品字体控件移动到顶部，保留原事件和保存逻辑；五种业务单证共用紧凑抬头，但保留各自内容组合。
- `assets/configurable-workspaces.js` 为产品字段启用主从编辑；语言设置提供真实内置项，不把改名当作新增翻译能力。
- 客户工作区增加全部、今日、逾期、本周跟进概览；移除重复的客户工作区设置界面，统一使用主设置。
- 历史列表新增数据库端分页和轻量摘要，不下载全部历史图片、签章、模板；打开、复制及导出具体记录仍读取完整快照。
- 修复打印容器引发的空白尾页以及预览尺寸观察循环；短单证压缩留白，产品图片仍保留。

## 数据与兼容

- 未删除任何业务表或历史记录；新增的两个历史查询索引使用 `IF NOT EXISTS`，可重复执行。
- 原 `/api/quotations` 与单条读取接口保留，历史单证快照、银行信息、签名与公章仍可使用。
- 所有验收使用独立临时数据库。打包程序测试复制本机已有激活文件到临时目录，没有修改生产资料或授权。
- 仍使用原有管理后台备份/恢复功能。升级前可备份数据库，故障恢复需保留原数据目录并使用该备份，不要删除用户数据目录。

## 已通过

- `npm run check`、`git diff --check`。
- `npm test`：项目现有测试套件，SQLite 测试前切换 Node 运行环境、结束后恢复 Electron 运行环境。
- 客户工作区、装箱单关联、产品库新增与引用、内置选项及保存、草稿关闭恢复测试。
- 历史分页：35 条记录分为 30+5，类型筛选 17 条；真实点击查看可打开，不请求全部历史快照。
- 历史查询性能：101 条含大快照的临时记录，第一页返回摘要；此为测试样本，不代表所有电脑的响应时间。
- 真实 Electron 导出 15 份 PDF：短报价和短 PI 含银行及签章各一页，多产品单据分页且无空白尾页；中英文 PI 条款隔离检查通过。
- PDF 渲染检查：公司名和标题、客户标签、列对齐、图片、收款信息及签名公章叠放。
- `npm run build:win`：Windows x64 安装包、blockmap 和 `latest.yml` 生成。
- `npm run test:packaged`：打包程序在 PATH 不含 Node、阻止外部网络的条件下启动；本地保存、离线字体、PDF 导出、客户页面、关闭重启及恢复测试通过。
