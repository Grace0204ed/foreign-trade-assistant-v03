# 外贸助手 Windows 本地安装版 0.5.0

## 在其他电脑使用

1. 打开 GitHub Releases，下载 `Foreign-Trade-Assistant-Setup-0.5.0-x64.exe`，不要下载源码 ZIP。
2. 双击安装包，按提示完成安装。适用于 Windows 10/11 64 位。
3. 双击桌面“外贸助手”。不需要 Node、命令行或开发环境；日常制单、客户跟进、保存历史和 PDF 导出可离线使用。

安装包尚未购买 Windows 代码签名证书，系统可能显示未知发布者提示。请核对下载来源及发布页 SHA256 后决定是否运行，不要关闭系统安全防护。

## 数据与升级

- 数据保存在当前 Windows 用户 `%APPDATA%/foreign-trade-assistant`，不在安装文件夹或旧源码目录内。
- 更新时先保存并退出软件，再运行新版安装包。不要删除数据目录。
- 安装包不包含个人客户、历史报价、公章、签名或上传文件。新电脑默认是独立数据，不会自动与另一台同步。
- 出差要带走完整资料：退出两台电脑的软件，备份上述整个数据目录，再将备份复制到新电脑的对应位置。新电脑若有资料，请先另行备份再替换，避免覆盖。
- 复制的数据目录包含客户及银行等敏感信息，只用自有安全介质传输，不要上传公开 GitHub。

## 与旧版的区别

内置运行时和数据库模块，不调用外部 node.exe；CRM、字体和图片资源随包安装。旧源码目录仅用于开发，不是日常运行依赖。安装版确认正常后，可将旧源码存档移走。
