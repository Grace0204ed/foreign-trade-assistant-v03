# 0.6.0 数据兼容、备份与恢复

- 业务数据目录保持为 `%APPDATA%\foreign-trade-assistant`，升级安装不会改名。
- `customers` 仅幂等增加 `group_name`、`labels_json`、`custom_fields_json` 三列；重复启动不会重复迁移。
- 按用户最终要求，首次升级会先在 `backups` 目录自动生成迁移前数据库副本，再清空旧新车报价、旧运价、国家路线和物流计算/合作伙伴记录。
- 起运港和目的港基础字典继续保留，供普通报价、PI、合同填写港口使用；它不再承担运费中心功能。
- 历史报价保存的金额、物流快照、公司快照与产品快照均不回写新模板。
- 产品字段被隐藏时，原值仍保留在产品 `values` / 快照数据中。
- 卸载配置继续使用 `deleteAppDataOnUninstall: false`，正常升级不会删除业务数据。

## 更新前备份

在“设置 → 管理后台”选择“备份数据库”，并复制整个 `%APPDATA%\foreign-trade-assistant` 目录到安全位置。

## 恢复

可在“设置 → 管理后台”使用“恢复数据库”，或关闭软件后用完整备份恢复数据目录。恢复前应再备份当前目录。
