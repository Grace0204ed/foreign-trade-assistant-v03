# 单证工作台（2026-10-12）

本次升级沿用现有桌面应用及数据结构，不迁移客户或历史报价。

## 商品图片与版式

商品主图默认显示在明细行前方，序号后面。主图为空时使用第一张附图。关闭“显示图片”会同时移除预览与PDF的图片列。
默认不重复输出下方图片墙。需要详细设备照片时勾选“附加详细照片”。
明细以商品信息、数量、单位、单价、金额和备注为主；型号、成色、HS等其他已配置列合并显示在商品信息下方，不删除原始数据。

## 自动保存

编辑停止400毫秒后保存一份本机恢复草稿（IndexedDB，可包含图片）。状态显示成功或失败。
重新打开应用后点击“恢复上次编辑”。每个登录用户保留最近一份恢复草稿，不替代历史报价，也不覆盖正式版本。
恢复时须检查当前所选公司。清理浏览器/桌面应用缓存会影响恢复草稿；需要长期保存时仍请点击“保存草稿”或“生成正式版本”。

## 五种单据

单据类型包括报价单、形式发票、销售合同、商业发票和装箱单。
切换类型共用当前客户、设备及价格资料。点击“另存当前单据（关联原订单）”产生独立草稿，记录原订单编号；旧文件不跟随修改，避免影响已签文件。
装箱单只列商品，不列运费等费用行，不显示单价、金额及银行付款资料。展开“装箱资料”填写各商品行合计件数、净重kg、毛重kg、体积m³和唛头。输出前必须补齐正数，件数为整数，毛重不得小于净重。
装箱汇总不会把空白当作零；尚缺数据的汇总显示横线。

## 语言、预览与颜色

补充纯法语入口；系统固定字段按所选语言显示。自定义文案可在“各语言商品及条款文案”中分别保存中文、英文、法文或西班牙文。不会将未经确认的机器参数或质保承诺自动改译。
纯外语输出若检测到中文，工作台会提示人工核对。公司名称、地址和银行等既有资料仍需在公司设置中保证外语文案准确。
预览支持适合宽度、75%、100%和125%。打印时强制恢复正常A4尺寸，表头重复，尽量避免商品行跨页；超长单行仍可能跨页。
共9款样式：商务金色、黑金、蓝白、酒红、森林绿、深海蓝、石墨灰、青绿和紫罗兰。

## 启用与验证

先保存当前工作，完全退出桌面应用后重新打开，确保前端和本地服务一起加载新版本。
本次没有修改实际客户数据库，没有自动生成或覆盖任何正式报价。
运行 `npm run check`、`npm test` 验证基础功能。浏览器回归脚本为 `scripts/test-document-workspace.js`，需要通过环境变量指定 Playwright 和浏览器路径；可选 TEST_SOURCE_DB 仅用于创建隔离备份，原数据库只读。
