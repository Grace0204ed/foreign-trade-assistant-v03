# 系统 PI 紧凑排版

本轮将用户要求的紧凑 PI 排版落实到系统预览和导出，而非重新制作客户已导出的文件。

## 修改范围

- 新版 PI 联系方式在左侧紧凑排列，编号和日期右侧对齐；缩小抬头、说明与空白邮箱行占用。
- 将设备、拖车、港杂、海运与保险等输出为一张表，使用原有配置生成的单元格，不重新计算价格或改动录入数据。可见的品牌、型号、海关编码、备注、图片和自定义字段保留在对应描述中；后台隐藏字段不会被带出。
- 读取原配置中的字段标签、顺序和显隐。隐藏描述时，其他已显示且有内容的字段保留为独立列，避免丢失资料。单据语言、颜色、文字样式和收款／签署控制沿用现有功能。
- 新建及复制 PI 使用排版版本 2，并随保存、历史快照和草稿恢复保留。没有新版标记的旧历史保持版本 1；用户明确指定的现有单据可单独更新标记，不批量改历史。
- 修复启动时偶发在后置组件尚未加载时初始化的问题：组件声明在启动前加载，初始化等待 DOMContentLoaded，不用固定延时。
- 公司账户变更仍是本机业务设置，不将客户信息、真实账号或具体单据数据写入源码。

## 已完成的针对性验证

- 实际 Electron 页面及 PDF 截图对照：紧凑抬头、左右对齐、一张费用明细表；英文、中文及法文。
- 五类条目及定金／尾款金额校验，预览和导出 PDF 字节一致，电子文档连续长页、A4 打印自然分页。
- 图片、可见自定义字段、隐藏字段、隐藏描述列及浅色表头对比度验证。
- 保存后历史重开、真实关闭重开恢复，排版标记与费用数值保持；草稿不覆盖历史，旧 PI 排版及其他单证类型保持。
- 新版组件与初始化连续重跑，首页启动和表单配置专项验证。
- 七类单证字段保存重开及实际 PDF、四类金额大小写与运输条款专项验证通过。

正式发布以本次提交的 GitHub Actions 回归与安装包构建为准；公开版本不覆盖，发布成功不等于已安装到用户电脑。
