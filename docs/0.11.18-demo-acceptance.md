# 新版 Demo 落地核对

依据：document-workflow-review-demo.html，应用锁采用“静谧蓝 · 居中”。

本轮不替换用户数据，不修改历史单证快照，不将设计示例数据注入正式数据库。

已通过独立测试数据库验收（2026-11-01）：
- 产品录入：分组式双列弹窗、图片区、可收起运输资料，固定保存操作。
- 规格参数：自由文字／字段模式、参数名称类型单位设计、保存重开、引用及目录输出。
- 产品导入：统一弹窗，文本／文件、模板表头下载、核对后确认入库。
- 行业模板：机械、服饰鞋帽、五金、化工、3C；复制后可编辑。
- 产品目录：按模板字段预览，PDF／打印明确分开。
- 佣金：工作台一个入口，历史分类合并展示，旧协议数据保留原文。
- 多单证准备及输出开关：按 Demo 卡片与滑动开关实现。
- 应用锁后台：按 Demo 重做布局，保留验证当前 PIN 的保护。

实际验证：产品新增、选中编辑、取消、保存重开、价格范围与图片；规格字段改名及零值保存；行业模板复制与字段保存；文本及 Excel 识别、核对取消及确认入库；目录实际 PDF 内容；佣金工作台入口与历史筛选；应用锁开关、提示、错误 PIN 拒绝和正确 PIN 解锁。

已通过 test:product-modal、test:refinement、test:fields、test:pdf、test:next、test:demo-workflow、npm test 和 npm run check。已生成 0.11.18 Windows x64 安装包。

实际打包程序测试已通过：移除 PATH 中 Node 运行环境后仍可启动，本地保存、离线字体、PDF 导出、同名文件隔离、取消导出、关闭写入失败保护、关闭重开恢复单证和产品草稿、CRM 访问均通过。测试使用临时数据库，不写入用户正式数据。

截图和输出：output/demo-roundtrip/ 下的 lock-settings.png、lock-screen.png、import-modal.png、catalog-preview.png 和 catalog.pdf；产品编辑截图见 output/product-modal-qa/。这些文件为本机验收材料，不向发行包注入测试业务数据。
