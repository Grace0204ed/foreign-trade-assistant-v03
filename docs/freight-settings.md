# 运费查询与后台设置

进入「设置 → 国家、港口与运费设置」，或点击运费查询右上角的同名入口。

## 修改页面

- 展开「板块标题与字段名称」，可改常用港口、计算运费、附加费用明细、常用货物体积及计算字段名称。
- 常用航线支持自定义显示名称、起运港、目的港、显示开关和删除。
- 地区是一级分组，国家是二级分类；两级均可新增、改名、删除。国家可以关联本国或邻国港口。
- 点击「保存运费设置」才会生效。「取消修改」恢复上次保存内容。
- 删除地区、国家或常用航线入口不会删除历史报价或运价库。

运费查询只展开当前选择的地区和国家。默认提供非洲、南美洲入口；津巴布韦关联贝拉、德班、达累斯萨拉姆。路线属于可编辑参考资料，实际可运输性须与货代确认。

## 更新货代运价

复制「货代填写模板」发给货代，收到后粘贴到文字框，点击「识别并预览」，核对后点击「确认批量更新」。

同月份、同货代、同起讫港、同运输方式、柜型、计费方式及币种匹配时更新原记录；新月份新增。客户国不作为重复维护运价的依据。端口匹配不清、日期无效、重复记录或卸货国家不一致时需要先修正。

价格填写「待询价」或留空，不按已报价的零元处理。运价与设备体积分开维护；输入型号不自动选择机器，点击候选才引用数据，自动计算不覆盖手工修改的体积。
