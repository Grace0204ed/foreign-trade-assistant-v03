# CI 与销售合同模板修改记录

日期：2026-11-16
版本：0.11.52
依据：用户提供的六页 PDF，以及随后明确的“CI”“开始修改”。本轮适用商业发票和销售合同；运费代付协议单独列项，尚未新增。

- CI：保留后台配置的横向商品字段和连续条目分组，使用公司 Logo 与彩色标题栏、卖方／买方资料、付款交付条款、收款和独立双方落款。
- 合同：Logo 与公司栏、逐项设备清单、贸易条款、设备状况及双方义务等分组正文；字段仍取现有商品和后台配置，不改变填写页结构。
- 付款金额按分计算，订金四舍五入、尾款取总额减订金；支持自定义比例，未定价单据不展示完整应付分摊。币种与金额大写对应，保留双币种金额输出和后台总金额显隐。
- 合同正文可在销售合同设置维护语言、正文、顺序、显隐及适用新旧设备。新设备不套用二手设备说明；混合订单列明对应的二手设备。
- 新合同保存完整条款快照，后台修改不改写既有记录。旧 CI／合同保留原纸面版本。新增公司账户联系电话为选填，沿用原账户和签署配置。
- 国家有资料且后台允许显示时带入 CI，不增加前端必填项；原公司／个人买方填写及其独立资料保留。
- 电子 PDF 保持连续长页，纸张打印自然分页。未采用扫描件的手写签名、客户盖章或样例编号。

## 已运行的针对性验证

- 精确金额及大写边界、分摊舍入、币种和版本兼容检查。
- 实际 Electron 界面、合同正文连续键盘输入及后台保存；中文、英文及八种外语条款渲染。
- CI／合同实际电子 PDF、A4 打印、图片、混合条目、待询价、总金额显隐、文字样式、无 Logo 布局和输出越界检查。
- 实际保存历史、重新加载、后台修改后历史隔离；真实关闭进程后分别恢复两类草稿、不重复、不覆盖其他草稿及历史。
- 原八类填写顺序、七类字段保存回读及 PDF、批量制作、报价单配置验证通过。

正式发布以本轮精确提交的 GitHub Actions 完整回归和安装包构建为准。未进行用户桌面覆盖安装或实体打印机出纸验证。
