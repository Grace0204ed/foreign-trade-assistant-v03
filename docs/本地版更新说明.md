## 使用更新

先保存当前单证，完全退出外贸助手后重新打开，前端和本地服务才会一起更新。现有客户和历史数据不删除、不上传 GitHub。

源码运行：安装 Node.js 后在项目目录执行 `npm ci`、`npm run electron`。打包 Windows 安装包执行 `npm run build:win`。不要将免登录本地服务改为公网监听。

## 自检

`npm run check` 与 `npm test` 检查语法、佣金、采购及历史操作；`scripts/test-local-workflow.cjs` 使用临时独立数据库测试本地监听、禁用登录、客户传递、草稿切换、费用行和历史保存，需要设置 PLAYWRIGHT_PATH 与 TEST_BROWSER。
