# 0.11.10 客户管理正式版改动

## 使用位置

- 侧边栏“客户跟进”：新版客户列表、搜索、分组/状态筛选和右侧客户详情。
- “设置 → 客户管理配置”：客户字段、分组、状态、标签、跟进设置。
- 客户页“客户管理设置”直接打开对应设置页；返回首页不经过单证编辑器。

## 配置与数据

字段以稳定的字段键绑定，而不是以名称或顺序识别。名称、类型、显示/必填和拖拽排序可编辑。下拉字段支持配置选项；旧客户引用的历史选项仍可保留。

客户姓名、公司、电话、国家、需求仍使用现有客户表字段；其他字段写入 custom_fields_json。配置写入已有 company_settings，不新增或清空业务数据表。更新客户保留未知自定义值、跟进记录和已有设备需求标签。

删除字段只是移除当前配置并保留原值；删除分组、状态和标签不批量修改历史客户。此版本不自动建立客户与单证的关联。

## 其他已确认修改

- 移除侧边栏单独的“联系我们”，使用说明中的联系方式保留。
- 启动不再自动弹恢复窗口；可主动点击“恢复上次编辑”。关闭时等待写入，若有未写入内容则提示保存草稿或取消关闭。

## 验证命令

- `npm run check`：语法检查。
- `npm test`：原业务与更新选择等回归测试，结束后恢复 Electron 的 SQLite 模块。
- `npm run test:customers`：临时数据库下客户资料编辑、历史保留、跟进要求、配置保存重开、拖拽排序、隐藏字段和历史分组兼容。
- `npm run test:recovery`：独立进程重启、草稿与 PDF 内容隔离。
- `npm run test:packaged`：实际打包程序离线启动、保存、PDF、关闭取消/写入失败及重新打开；测试需本机已有有效授权，使用隔离数据副本。

## 升级

正式安装包和 latest.yml、blockmap 一起发布。现有软件通过设置中的软件更新下载安装；不需要另装 Node.js。安装更新不会主动删除本机数据。建议更新前使用管理后台备份数据库；需要恢复时使用原备份恢复功能。

本地编译通过不等于 GitHub 已发布；发布状态应以 GitHub Release 的完整安装包及更新元数据为准。
