# 本次修改范围

按用户最新照片及已提供的塔吉克斯坦 CI／合同样本处理付款金额。报价单、形式发票、商业发票、销售合同在付款明细顶部显示数字总金额和大写，下面按已选付款比例自动计算订金、尾款，自定义付款节点沿用已填内容。原数字合计保留，其下同步列出订金、尾款金额，和下方付款明细一致。人民币中文及中外文组合显示中文财务大写；外币显示带实际币种的英文金额。未定价单据保留小计语义，不把部分价格当作完整合同金额。未修改公司、账户、历史、草稿存储，也未重做填写页、导航或工具栏。

EXW 委托运输原先复用了海外目的港 datalist，本次限定为当前港口资料中的中国境内有效港口／口岸，可继续手动输入交接地点。CIF、CFR 海外目的港及 FOB 境内交货港保持原规则；按贸易方式和运输模式分别保留输入。

Windows 输入问题独立于旧授权书的逐字重绘问题。当前 Electron 运行环境能复现原生阻塞弹窗后的窗口／页面焦点不同步：窗口激活但 `document.hasFocus()` 为 false。参考 Electron 官方已确认问题 https://github.com/electron/electron/issues/40212 及修复 https://github.com/electron/electron/pull/54380 。不升级整个运行环境，在用户实际点击可编辑控件且页面失焦时请求主窗口恢复焦点；只允许已注册主窗口的主页面，窗口必须可见且已激活，正常点击不重置焦点，不抢其他窗口焦点。

## 验证

- 原生窗口复现阻塞弹窗后的焦点不同步；真实点击恢复、连续英文、中文输入、正常点击不重复恢复。
- 实际填写页在 100%／75% 缩放连续输入装车地点、口岸、代付说明、自定义付款节点、交货时间和备注。
- EXW 境内选项、CIF 海外选项、FOB 无目的港／柜型；切换后分支数据保留，实际重新加载后从草稿入口恢复口岸。
- 四种单证实际电子 PDF 和 A4 打印数据包含数字与大写，30/70 自动分配，中文财务大写、小数、待定价边界；对生成纸面和 EXW 填写界面进行视觉检查。
- 正式发布以本提交的 GitHub Actions 必要完整回归及安装包构建结果为准。不能据此声称已在用户其他电脑安装或已经排除该电脑所有卡顿原因；用户报告的具体机器仍需更新后使用验证。
