# 0.11.15 填写界面验收

本轮修正 0.11.14 未真正替换主填写结构的问题，而非再次只调整间距。

## 实际范围

- 报价单、PI、销售合同、商业发票、装箱单共用新的卡片、分区和明细编辑结构；保持五类单证各自的字段配置。
- 常用明细字段在主行，其余已配置字段在同一条目的“更多字段”展开。字段没有删除，仍通过原有字段键保存和输出。
- 保留图片上传、移除及预览/PDF；界面采用上下布局，窄屏表格横向滚动而不继续压缩输入框。
- 历史单证内容、编号、模板快照及各类 PDF 独立版式不被迁移替换。本轮没有重写邀请函、授权书独立表单。
- 新单证按 QA/PI/SC/CI/PL 分别编号；复制使用对应类型前缀。
- 发布说明自动读取当前版本更新日志，不再使用笼统的修复描述。

## 本地验证

- `npm run check`：通过。
- `npm test`：通过，自动切换 Node/Electron SQLite 二进制并还原。
- `npm run test:ui`：通过，包含产品库、装箱引用、草稿保存/恢复和重启；测试中的磁盘失败为故意注入并验证的异常。
- `npm run test:approved`：通过，包含历史分页和原有模板/快照兼容性。
- `npm run test:refinement`：通过，包含新加入的真实 Electron 五类编辑器检查、标题按钮同行、折叠海关编码保存、编号前缀。
- `npm run test:pdf`：通过，15 份实际 PDF 无空白页、短单证一页、客户和表头列映射检查通过。新增界面 CSS 仅作用于屏幕，不改变打印版式。
- 实际查看 PI 基础资料、展开明细和 1024 像素窗口装箱单截图；输出在 `output/demo-editor-qa/`，不随发行包携带。

本地测试使用临时数据库，未修改本机真实客户、产品、银行或签章资料。构建、安装包运行验证和发布由 GitHub 工作流独立执行；不把本地测试通过等同于其他电脑已完成在线升级。
