# 0.11.14 本地验收记录

## 实施范围

- 产品库支持选中一条后编辑，未填写价格或图片的记录同样可编辑；保留原记录编号、图片、自定义字段及历史单证快照。
- 产品录入统一使用模板字段，移除重复的年份、工时、价格和币种输入；价格支持范围。
- 粘贴文本导入提供表头识别、字段映射、数据预览及重复处理，确认前不写入产品库。
- 移除旧价格表导入、TXT/CSV 上传、旧机械参考目录入口及内置资料文件；本机数据库已有产品不删除。
- 七类单证保持独立格式；当前单证绿色标识，填写区在上、预览在下。文字样式弹层支持再次点击、点击其他区域、Esc 或切换页面关闭。
- 移除可见的单据样式选择和硬编码的签署人默认值；报价抬头主题色与 PI 对齐，保持紧凑布局。
- 正式报价不再自动修改 CRM 跟进阶段；新安装仅有通用演示公司、产品和张三客户。

## 数据兼容

产品表新增 template_name 和 values_json，迁移先检查列是否存在，可重复执行。编辑合并已有字段，隐藏字段不清除；删除全部演示产品或客户后重启，不会再次自动生成。升级不重置已有公司、产品、客户和历史数据。

更新前在管理后台备份数据库，并保留完整私人数据目录（含上传文件）。恢复时先关闭软件，通过后台恢复备份；上传图片、签名、公章等应与私人目录一起恢复。旧内置参考目录可从 Git 先前版本恢复，不影响数据库内已有产品。

## 已执行的验证

- npm run check：通过。
- npm test：通过；包含 SQLite 运行时匹配、更新版本与安装包选择、授权安全、历史操作、配置字段及发布完整性等测试。
- npm run test:refinement：通过；实际 Electron 中验证编辑、范围价格、字段保留、导入确认、重复处理、重新加载及七类单证交互。
- npm run test:approved、test:next、test:customers、test:ui：通过；覆盖历史分页、界面布局、客户配置、装箱单引用、产品库及草稿进程重启恢复。
- npm run test:pdf：通过；15 份实际导出 PDF、共 34 页，无空白页，短报价及短 PI 含收款和签章内容时为一张 A4，条款文字完整。
- npm run test:languages：通过；七类单证乘九种输出语言，共 63 份实际 PDF，验证文字、表头、字段对应、阿拉伯语方向及分页。
- 已渲染并人工查看产品编辑、窄窗口填写、报价、PI 和装箱单页面；核对抬头配色、图片、客户标签和表格列对齐。

以上测试使用隔离的临时数据库，不修改用户真实资料。草稿恢复套件中的模拟磁盘写入失败为主动注入的错误，用于验证失败后保留编辑内容，并非实际业务数据损坏。

## 发布与更新验证边界

Windows 发布流程先执行测试，再构建安装包；打包后自动启动独立隔离数据目录的程序，校验内置运行时和 SQLite。安装包、blockmap、latest.yml 的版本、大小及 SHA512 完整一致后才公开 Release。

本地验收不代表已在所有办公室电脑实机安装。GitHub 发布及在线更新检测结果以本次发布后的实际核对为准；不自动安装或重启用户当前电脑。
