# 报价入库、工厂交货及买方留空

本轮只调整用户新确认的报价产品入库、EXW／FOB 显示和买方可留空；沿用现有产品编辑窗口、单证导航及保存机制。

后续追加：单证选择栏可直接选择制作公司；签名版本可选“不使用电子签名”，公章独立开关，落款资料与手写签字、手动盖章位置保留。各单证公司、收款、签署快照独立，后台公司资料不被切换或改写。派生单证继承源单公司的快照及账户，避免公司与账户混用。

- 商品行增加“保存到产品库”，带入名称、品牌、型号、新旧属性、单价、币种、照片、海关编码及原有自定义资料。用户可在现有窗口补充分类后保存，不将报价数量乘到产品单价。
- 保存中的重复点击受保护；来源标识随草稿恢复，关闭进程后先恢复产品编辑、再恢复报价，仍能识别同一商品已入库。报价及历史资料不被入库操作覆盖。
- 产品编辑窗口提升到页面公共层，确保在报价页打开时实际可见，不受隐藏的产品库页面遮挡。
- 旧配置补齐工厂交货地点；EXW 不委托运输时默认“中国工厂”，允许直接输入其他地点，起运港不输出。各贸易方式填写值分别保留。FOB 编辑与新单据输出显示“交货港”，CIF 起运港和海外目的港维持原规则；已锁定旧历史保留原快照。
- 买方身份增加“不填写”。隐藏标准及自定义买方填写项，输出移除空白买方资料及买方签署。个人与公司资料仍按原独立档案恢复。
