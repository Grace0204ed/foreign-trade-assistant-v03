# 新 Demo 正式接入

本轮参考 `document-settings-refined.html` 与 `customer-management-demo.html`，将界面接入原有设置和客户数据模型，而非加载演示资料。

## 已接入

- 七种单证共用字段列表与属性面板；PI 继续使用基础信息、商品明细、付款及交付条款、预览及版式的业务板块。
- 字段名称、类型、必填、显示、子字段和同级拖拽仍写入现有 documentConfigs / quoteTemplateConfigs。
- 下拉选项保留固定 ID 和内部值；简单模式编辑中英文，复杂层级和条目业务属性在高级设置中保留。
- 客户管理可在工作区切换设置，复用系统设置里的同一配置组件及保存接口。
- 不改变历史单证快照、客户字段键、已保存字段值或 PDF 内容渲染规则。

## 验证

`npm run test:customers` 使用独立临时数据库和 Electron 浏览器窗口，验证配置持久保存、客户编辑与跟进保留、字段拖拽、七种单证入口、子字段取消和下拉实时预览；保存实际运行截图。

另外执行 `npm run check`、`npm test`、Windows 安装包构建及打包应用检查。具体执行结果以本轮交付记录为准。

无需数据迁移。不替换用户公司、签章、产品或客户数据；发布后通过原软件在线更新安装。
