# 统一产品库与分类确认

本轮按用户最新要求修复产品保存、选品引用和分类确认，不调整单证版式或签署设置。

## 已确认的问题与修改

- 当前存储实际已有同一份产品集合；报价新保存的商品分类为空，加上选品保留旧筛选，造成搜索不到的体验。选品打开时刷新共同集合，输入新关键词时清除旧分类、品牌筛选，图片使用共同来源。
- 产品读取遗漏顶层新旧状态，现完整保留。卡片显示型号、年份和全新／二手，已知不同年份或状态分别保存；其他同品牌同型号记录提供替代、单独保存、取消三个选择。
- 商品名称匹配已有分类；没有对应分类时显示建议名称、所属类型，允许修改后确认创建。取消不创建分类、不保存该新商品。自定义名称保留原建议名称为别名。
- 现有缺分类记录只自动补入已经存在且可识别的分类，修改前生成备份。未知分类在用户操作时确认。保留既有明确分类、原商品和历史单证，不对原目录批量改名或合并。
- 替代保存保留原产品编号、历次报价来源、自定义资料和未重新上传的照片；明确移除照片仍可生效。
