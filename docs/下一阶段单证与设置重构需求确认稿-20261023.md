# 外贸助手下一阶段单证与设置重构需求确认稿

记录日期：2026-10-23  
状态：仅记录，尚未开始修改代码  
启动条件：用户明确说“开始修改”后再实施

## 一、总体设计原则

1. 外贸助手为本地单用户软件，不设置用户、账号、角色和权限体系。
2. 所有单证采用统一的可配置结构，不再为某一种商品单独维护固定业务页面。
3. 统一结构为：`单证类型 → 单证模板 → 板块 → 字段 → 第三级选项`。
4. 产品信息的数据流为：`产品库 → 产品模板 → 当前单证明细字段`。
5. 单证模板决定编辑界面、预览和 PDF 输出；不能出现选择了模板但页面仍展示固定字段的情况。
6. 历史单证保存模板和字段快照。以后修改模板，不得改变已经保存的历史单证。
7. 不同单证分别设计自己的填写页面和正式版式，不把报价单、PI、合同、商业发票、装箱单等强行做成同一界面。

## 二、设置页面顺序

设置页按以下顺序排列：

1. 公司信息设置
2. 产品模板
3. 报价单设置
4. PI／形式发票设置
5. 销售合同设置
6. 商业发票设置
7. 装箱单设置
8. 邀请函设置
9. 授权书设置
10. 客户管理
11. 管理后台

删除独立的通用“单证设计器”。设计和字段设置分别放入每一种单证自己的设置页。

## 三、统一删除的旧业务逻辑

1. 删除“选择报价业务”板块及“标准产品报价”按钮。
2. 删除固定“新车报价格式”及其专用生成、判断和历史统计逻辑。
3. 删除独立运费中心、旧运费报价记录和旧运费分类业务；只保留全局悬浮运费计算器。
4. 删除“产品分类与报价字段”旧模块及一级、二级产品分类层级。
5. 删除报价明细里的“产品类别”，因为报价模板已经确定业务类型。
6. 删除报价明细里的“设备状态／Condition”。
7. 删除旧的固定字段按钮／标签选择界面。
8. 删除“关联客户”下拉框；保留粘贴识别和手工填写客户信息。
9. 删除“底部有效期说明”字段；报价有效期由报价日期和截止日期自动生成。
10. 删除报价页面里的“预览缩放”和“各语言商品及条款文案”编辑区。
11. 删除管理后台的“新车组合基础数据”、保存到产品库、清空及对应旧逻辑。
12. 删除用户数量、用户列和 admin 等用户概念。
13. 删除“导出全部数据”和“导入数据”功能。

## 四、需要保留的功能

1. 保留当前单据的签名／公章显示控制。
2. 保留草稿自动保存和恢复上次编辑。
3. 保留客户资料粘贴识别和手工填写。
4. 保留数据库备份、恢复数据库、打开数据目录和数据查看。
5. 保留客户、产品、普通报价、跟进记录等有效业务统计。
6. 保留历史单证及其查看、预览和导出能力。
7. 保留全局悬浮运费计算器，但不得遮挡主界面。

## 五、产品模板与报价模板的边界

1. 产品模板放在“公司信息设置”之后。
2. 产品模板用于定义某类商品可录入和可调用的产品字段，例如品牌、型号、年份、发动机、规格、图片等。
3. 报价模板用于定义报价单的板块、明细列、显示顺序、标题和版式。
4. 删除“产品类别”后，产品层级使用：`报价模板 → 品牌 → 型号`。
5. 产品模板、报价明细列和分类字段配置不能再各自维护一套重复字段定义，应合并成一个字段来源。
6. 隐藏或停用字段时，只影响新编辑和展示，不得删除已有产品或历史单证中的字段值。

## 六、每种单证的板块化设置

以报价单为例，设置页至少包含：

1. 报价基础信息
2. 客户信息
3. 报价明细
4. 贸易条款
5. 收款信息
6. 签名与公章
7. 预览及版式

每个板块的二级字段均支持：

- 修改中英文名称
- 新增
- 隐藏／显示
- 删除或停用
- 排序
- 设置必填／非必填
- 选择输入类型

输入类型至少包括：单行文本、多行文本、下拉选择、日期、数字／金额、复选框、图片、字典选择器。

字段保存后必须同步出现在：正式编辑页面、预览、PDF 和历史记录中。

## 七、客户信息板块

默认字段可包含：客户公司、客户国家、公司负责人、公司电话、邮箱、地址。

用户可将字段名称改为“买方公司名称”“买方国家”“公司负责人电话”等，也可新增、隐藏、停用、删除和排序。

客户管理保存完整客户资料；单证模板只决定本单证调用和展示哪些客户字段。两者不能混为同一套配置。

## 八、报价明细板块

默认字段可包含：

- 条目类型
- 商品信息／产品描述
- 海关编码
- 品牌
- 型号
- 数量
- 计费单位
- 单价
- 金额
- 产品图片
- 备注

金额由数量和单价计算，不再保留可与计算结果冲突的独立总金额来源。

全单币种作为默认币种；只有明确启用混合币种模式时才显示行币种及换算逻辑。

## 九、第三级选项

海关编码等字典型字段支持第三级配置。例如：

`报价明细 → 海关编码 → 挖掘机海关编码`。

第三级选项支持：

- 新增、修改、删除／停用、隐藏和排序
- 中英文显示名称
- 实际保存值
- 搜索别名／关键词
- 默认值

可采用同样结构的字段包括：品牌→型号、币种、计费单位、贸易条款、付款方式、运输方式、起运港／目的港、质保方案、售后方案、银行账户、邀请目的、费用承担方、授权类型和授权范围等。

不再建立“产品类别”第三级逻辑；报价模板已经承担业务分类作用。

## 十、重复业务逻辑合并规则

1. 报价模板与产品类别重复：保留报价模板，删除产品类别。
2. 产品模板字段、全局报价列和分类字段配置重复：合并为统一字段来源。
3. 模板总金额与计算金额重复：只保留计算金额。
4. 全单币种、行币种和换算来源重复：默认使用全单币种；混合币种按需开启。
5. 产品模板中的贸易条款与单证贸易条款重复：贸易条款归单证设置管理。
6. 付款比例在贸易条款、银行信息、PI 和合同中重复：付款条件归当前单证，银行板块只保存收款账户。
7. 港口在贸易条款、旧运费模板和计算器中重复：单证贸易条款是正式来源，计算器只计算并经确认回填。
8. Charge Type 与条目类型重复：只保留条目类型。
9. 单据样式选择与设计器重复：样式配置归每种单证设置。
10. PDF语言与独立多语言文案编辑器重复：保留输出语言，删除独立文案编辑器。
11. 产品图片字段、图片列、显示图片和照片附录重复：统一为一个图片字段及简单输出控制。

## 十一、预览与输出

1. 单证预览区域铺满右侧可用宽度。
2. 保持 A4 比例，随窗口宽度自动缩放。
3. 调整窗口大小时自动重新适配。
4. 屏幕预览缩放不得改变最终 PDF 的 A4 尺寸和分页。
5. 正式预览和 PDF 尽量共用渲染规则，避免排版差异。

## 十二、管理后台与应用锁

管理后台增加本地应用锁：

- 可开启／关闭
- 可设置 PIN 或密码
- 支持手动锁定
- 支持无操作自动锁定
- 锁定后隐藏客户、报价、产品和历史数据
- 解锁后返回原页面，并尽量保留未保存内容

应用锁只是本地隐私保护，不建立用户、账号、角色或联网登录系统。

## 十三、实施约束

1. 当前阶段仅保存需求，不修改代码。
2. 开始修改前先检查旧模块引用关系和数据结构。
3. 删除旧逻辑时同时清理入口、组件、接口、样式、统计和只服务于旧功能的数据。
4. 保留历史正式单证的查看和导出兼容；用户已明确不需要保留旧新车报价及旧运费业务数据。
5. 不覆盖无关的用户改动。
6. 完成后分别说明：代码完成、本地测试、安装包生成、GitHub 发布和升级验证的真实状态。

## 十五、双币种／双价格显示

1. 报价主币种与第二显示币种是两个正式报价展示币种，不再使用含义含糊的“外币费用币种”。
2. 用户可只显示一个币种，也可开启双币种并列显示，例如人民币报价同时显示按汇率换算的美元或英镑价格。
3. 用户填写主币种、第二币种和汇率，并清楚显示换算关系：`1 主币种 = N 第二币种`。
4. 每行单价、每行金额、报价小计和总计均应按选择显示主币种，开启双币种时同时显示第二币种金额。
5. 汇率允许用户手工填写；如果后续增加在线查询，查询结果必须显示时间和来源，并允许用户确认后采用，不能静默改变已保存报价。
6. 保存单证时保存币种和汇率快照，日后汇率变化不得改变历史单证金额。
7. 费用行原则上继承当前报价主币种；混合币种费用必须先按明确汇率换算后才参与合计。

## 十六、报价模板与产品库模板的可选关联

1. 报价模板代表业务报价类型，例如“二手工程机械”“油漆产品”“泵车”等。
2. 产品库录入模板与报价模板可以建立对应关系。例如选择“油漆产品”报价模板时，可关联油漆产品库模板及其乳胶漆、底漆、清漆等产品字段。
3. 报价模板提供两种模式：
   - **引用产品模板**：报价明细字段跟随所选产品模板；从产品库选择产品后，可自动带入对应规格参数和图片。
   - **独立设计**：报价模板自行设置需要展示的明细字段，不强制继承产品模板。
4. 独立设计模式仍可从产品库选择产品；系统只自动填入字段键匹配或用户已建立映射的内容，其余字段由用户手工填写。
5. 引用产品模板后，不应把产品库全部字段强制输出；报价模板可以进一步设置哪些字段显示、隐藏和排序。
6. 每个报价模板保存关联的产品模板 ID、字段映射和展示字段快照。
7. 产品库中的完整数据继续保留；报价单只保存和展示本次报价所采用的字段快照，避免以后修改产品或模板影响历史报价。
