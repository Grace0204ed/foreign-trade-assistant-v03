# 显示设置 Demo：确认与正式接入

用户要求：删除附加详细照片功能。每个商品只在填写区上传一张图片，图片是否显示继续使用商品明细上方的“显示图片（页面预览和PDF）”，显示设置面板不能再重复放图片开关。

签署方式改为明确的版本选择：

- 手动签名／盖章（自动落款）：自动带入所选公司的名称、签署人、职务和单据日期；买方落款读取已填买方资料。手写签字线和盖章位置留白，不印电子签章素材。手动模式不清空已有姓名、职务、日期。
- 卖方与买方落款独立勾选并自动保存，可显示双方、仅卖方或仅买方。关闭买方落款只去掉买方签字区，正文中的买方资料照常保留，不要求客户签名回传。
- 电子签名／公章：展开签名版本与电子签名、公章的独立显示选择。

当前状态：

- 用户于 2026-11-21 明确确认“就要这样，开始修改吧”。正式源码已接入确认的小面板：顶部显示设置入口、抬头与内容、双方落款、手动／电子签署版本；收款信息开关与公司／类型／账户选择位于同一面板。
- 正式软件源码已移除“附加详细照片”入口、事件与重复状态显示；可编辑单证不再生成详细照片附页。
- 商品单图上传、商品明细上方的图片显示开关保留。旧历史、原图片与附图数据保留，不清理真实业务资料；已锁定历史继续使用原有快照。
- 针对性验证：报价纸面／单图开关及八类单证签章、收款控制检查通过；图片开关不会删掉商品图片，商品上传控件仍为单选文件。
- 本地正式界面已实际运行并截图对照，覆盖原生鼠标勾选、滚动、自动落款、仅卖方／双方、电子素材独立选择、四种实际电子 PDF、保存历史重开以及真实关闭进程重开恢复。版本 0.11.54 的正式回归与安装包交由该提交的 GitHub Actions 执行；桌面安装状态须独立核实，不以源码或发布代替安装验收。
