# 桌面版安装与代理模板使用

更新日期：2026-10-07。本次提供源码更新，不是新的独立 EXE 安装包。

## 首次安装

1. 安装 Windows 64 位 Node.js 24 LTS：https://nodejs.org/ 。安装时保留 npm 和添加到 PATH 的选项。
2. 打开仓库 https://github.com/Grace0204ed/foreign-trade-assistant-v03 ，点击 Code → Download ZIP。
3. 将压缩包完整解压到固定目录，不要在压缩包内启动。
4. 在该目录打开终端，依次执行：

```powershell
npm ci
npm run ensure:sqlite
npm run check
npm test
npm run electron
```

5. 以后双击“启动桌面版.cmd”即可。桌面版自行使用本机端口18765，不需要另外启动浏览器服务。

首次安装会下载依赖，需要网络。若命令找不到 node/npm，安装 Node.js 后重新打开终端。SQLite 报版本不匹配时，使用当前 Node.js 24 运行 `npm rebuild better-sqlite3`，然后再启动。

## 更新现有电脑

1. 先在旧系统“管理后台”点击“备份数据库”，确认提示成功；点击“打开数据目录”记下真实路径。
2. 关闭软件。将整个数据目录另行复制到安全位置，包含数据库、上传图片及其他配置，不能只保存程序文件。
3. Git 安装且没有本地源码改动时，在程序目录执行：

```powershell
git pull --ff-only origin master
npm ci
npm run ensure:sqlite
npm run electron
```

4. 如提示本地改动或分支冲突，不要使用 reset 或强制覆盖；可以将最新 ZIP 解压到新的程序目录，再启动“启动桌面版.cmd”。
5. 新旧软件不要同时运行。更新后从桌面菜单“视图 → 强制刷新”，或关闭后重开。

源码桌面版通常使用 `%APPDATA%\foreign-trade-assistant`，旧浏览器版或其他安装包可能使用 `%APPDATA%\外贸助手`；以系统显示的数据目录为准。不要删除任何一个目录，也不要用空数据库覆盖旧库。若记录为空，先核对数据目录，再通过“恢复数据库”选择自己的备份并重启。

## 使用三种代理文件

打开“授权代理”页面的“代理文件与模板”：

1. 在“文件类型”选择“代理授权书”“销售代理佣金协议”或“订单佣金结算单”。
2. 在“使用已保存模板”选择对应代理模板，点击“使用模板新建”。新文件自动产生编号，不覆盖原模板。
3. 编辑后点击“保存文件”，或“另存为模板”建立其他代理的模板。
4. 点击“导出当前文件 PDF”。授权书仍可分别导出公开版和带佣金版；协议与结算单不会因公开版开关隐藏核心条款。
5. 在“历史记录 → 代理授权”中查看、编辑或删除，列表会标明文件类型和模板。

佣金协议包含最低5%、加价不重复叠加、协商提高比例、客户保护，以及收到客户100%合同款后3–7个工作日内支付等条款。每笔订单需双方签署结算单。

结算单需填写客户、销售合同编号、关联佣金协议、币种、合同金额、比例或约定加价、代理人银行信息。应付佣金自动取“合同金额×确认比例”和“约定加价收益”中的较高者；比例不得低于5%。普通比例方式不使用加价栏。空金额不视为零价，收款银行未知时留空；不完整的非模板文件不能导出为完整结算单，但可保存待补充。

## Henry模板与隐私

本机已依据历史授权建立Henry的三类模板，并保留签名、公章和职务。结算单模板没有虚构客户订单和银行资料。

GitHub只包含程序、通用条款和说明，不上传Henry的证件、联系方式、签名、公章、客户历史或数据库。在另一台电脑下载源码不会自动获得这些私人模板。若是本人更换电脑，请通过安全渠道迁移自己的完整数据备份；不要把备份提交到GitHub。

## 验证与限制

自动测试覆盖最低佣金、加价不重复叠加、空值、模板编号、7种语言模式、历史批量操作。桌面源码启动依赖系统Node.js，暂未提供无需Node.js的新版独立安装器。

合同模板是已确认业务条款的生成工具，不替代正式签署和适用法律审查。手工填写的姓名、地址、银行资料及补充条款不会自动翻译，请按所选语言录入。
# 2026-10-09：个人采购模板与PI签章

在“代理授权”中选择文件类型“个人委托采购协议”，再选择本机已保存的个人模板，点击“使用模板新建”。编号按当天日期加序号生成。设备、年份、人民币采购款和服务佣金均可编辑，合计自动计算。模板支持中英双语、纯中文和纯英文；客户可以使用护照或当地有效证件，不要求中国身份证。

采购支持客户直付卖家或受托人代付；清洁和拖车另计，也支持直付服务方或代付。正式签署前需补齐甲方证件姓名、客户信息及取消采购时佣金处理约定。个人模板不显示公司抬头、公章或自动套用公司签名。

PI形式发票自动显示公司全称、职务、签署人、电子签名、公章及日期，沿用当前公司资料。个人模板资料、身份证、签名及公章仅在本机数据库保存，不随GitHub源码发布。更换电脑请单独安全迁移本机数据。
